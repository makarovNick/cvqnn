# CVQNN — комплекснозначная сеть с весами в корнях 4-й степени из единицы

Прикладной ресерч: что происходит с качеством классификации, если **каждый вес
сети зажать в одну из четырёх точек** {+1, −1, +i, −i}.

## Идея

На вес приходится ровно 2 бита (log₂4). В отличие от бинарных сетей {+1, −1},
здесь есть дополнительная фазовая степень свободы: умножение на `i` — это
поворот на 90°, который **перемешивает вещественный и мнимый каналы** сигнала.
Гипотеза в том, что эта фазовая связность частично компенсирует потерю точности
представления веса.

Обучение идёт по латентным FP32-копиям (`w_real`, `w_imag`), в forward они
проецируются на ближайшую вершину фазового квадрата, градиент проходит насквозь
(Straight-Through Estimator).

## Ключевые решения реализации

Их стоит держать в голове — в квантованных сетях результат к ним очень
чувствителен, и без них сеть просто не учится.

**Проекция.** `|Re| ≥ |Im| → sign(Re)·1`, иначе `sign(Im)·i`. Границы решения —
диагонали `Re = ±Im`, то есть биссектрисы между соседними вершинами; это
действительно ближайшая вершина, а не эвристика (проверяется брутфорсом в тестах).
`sign(0) := +1`, чтобы не рождать мёртвые нулевые веса.

**Weight decay не применяется к латентным весам.** Проекция масштабно-инвариантна:
важны только знаки и отношение `|Re|` к `|Im|`. WD не регуляризует сеть, а лишь
стягивает веса к нулю — в область, где решение о вершине максимально шумное.

**Клиппинг латентных весов в [−1, 1]** после каждого шага. Без него они уезжают
на бесконечность, выбор вершины «замерзает», и слой перестаёт обучаться.

**Нормализация делит Re и Im на общий средний модуль.** Это сохраняет фазу
сигнала — мы меняем только длину вектора, не поворачивая его. Обычный BatchNorm,
применённый к Re и Im по отдельности, фазу бы разрушил.

**Комплексное умножение — 2 вызова вместо 4.** Веса склеиваются в `[W_re; W_im]`
по выходной оси. FLOPs те же, но вдвое меньше запусков ядер.

## Диагностика

Помимо loss/accuracy пишутся две вещи, специфичные для квантования:

- **распределение весов по 4 вершинам** — вырождение в одну-две вершины означает,
  что фазовая степень свободы не используется;
- **flip rate** — доля весов, сменивших вершину за эпоху. Если он не падает к
  концу обучения, сеть не сходится к дискретной конфигурации, а болтается
  по границам решения.

## Протокол эксперимента

Абсолютная точность сама по себе ничего не говорит. Результат — это **дельта**
между двумя прогонами с одинаковыми сидом и архитектурой:

- `quantize = True` — веса в {±1, ±i}, 2 бита на вес;
- `quantize = False` — обычная комплексная FP32-сеть, 32 бита на вес.

Режим задаётся `CFG.mode` (`both` / `quant` / `fp32`) или переменной окружения
`CVQNN_MODE`. По умолчанию `both`.

## Запуск

Сначала локально, до траты GPU-квоты:

```bash
python smoke_test.py --train
```

Проверяет проекцию брутфорсом, сверяет комплексную алгебру с нативной
арифметикой `torch.complex`, проверяет сохранение фазы при нормализации и то,
что градиент доходит до каждого латентного веса.

На Kaggle GPU:

```bash
kaggle kernels push -p kaggle/
```
